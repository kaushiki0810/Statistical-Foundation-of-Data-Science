
# Practical 3: Understand Descriptive Statistics

## Aim
To understand descriptive statistics and analyse the Student Rating Dataset using Python and data visualization techniques.

## Objectives
- To explore the columns of a dataset.
- To calculate percentages using Pandas.
- To calculate mean and standard deviation.
- To understand the distribution of data using histograms.
- To differentiate between vertical and horizontal bar charts.
- To calculate the median of evaluation scores.

## Concepts Covered
- Dataset exploration
- Percentage calculation
- Mean and standard deviation
- Group-wise statistical analysis
- Histogram and age distribution
- Vertical bar chart using plt.bar()
- Horizontal bar chart using plt.barh()
- Median calculation

## Tools and Libraries Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
**StudentRatingDataset_evals.csv**

The dataset contains information about professors, including age, gender, ethnicity, rank and evaluation scores.

## Practical Description
This practical demonstrates descriptive statistical analysis using the Student Rating Dataset. It includes calculating the percentage of minority professors who are tenured, analysing mean age and standard deviation by rank, visualising age distribution through a histogram, comparing vertical and horizontal bar charts, and calculating the median evaluation score of tenured professors.

## Conclusion
This practical helped in understanding descriptive statistics through percentage, mean, standard deviation and median calculations. It also demonstrated how histograms and bar charts can be used to explore and visualise data.
