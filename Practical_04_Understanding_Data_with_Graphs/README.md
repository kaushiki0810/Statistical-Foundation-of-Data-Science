
# Practical 4: Understanding Data with Graphs

## Aim
To understand and analyse data using statistical techniques and graphical representations with Python libraries.

## Objectives
- To explore the Teaching Ratings dataset.
- To identify duplicate observations.
- To compare mean age and standard deviation before and after removing duplicate observations.
- To calculate average teaching evaluation scores by course division.
- To visualise the relationship between age and teaching evaluation.
- To analyse data based on gender and tenure using scatter plots.

## Concepts Covered
- Dataset exploration
- Identifying duplicate observations
- Mean and standard deviation
- Removing duplicate records
- Group-wise analysis
- Bar charts
- Scatter plots
- Data visualisation using gender and tenure categories

## Tools and Libraries Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
**TeachingRatings.csv**

The dataset contains information about professors, including age, gender, course division, tenure status and teaching evaluation scores.

## Practical Description
This practical uses the Teaching Ratings dataset to explore data through statistical calculations and graphical representations. It identifies duplicate professor records, compares age statistics before and after removing duplicates, calculates average teaching evaluation scores by course division, and visualises relationships between age, teaching evaluation, gender and tenure.

## Conclusion
This practical helped in understanding how statistical calculations and graphical representations can be used to explore and interpret data. Different visualisations, including bar charts and scatter plots, were used to analyse the dataset.
