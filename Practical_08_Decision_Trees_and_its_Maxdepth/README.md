# Practical 8: Decision Trees and its Maxdepth

## Aim
To implement a Decision Tree Classifier using the Pima Indians Diabetes Dataset and study how different maximum depth values affect the model's performance.

## Objectives
- To understand the concept of Decision Tree Classification.
- To prepare the dataset for model training.
- To divide the dataset into training and testing sets.
- To build two Decision Tree models with different maximum depth values.
- To compare the performance and accuracy of both models.
- To visualize the decision trees.
- To understand how maximum depth affects model complexity and overfitting.

## Concepts Covered
- Decision Tree Classification
- Maximum Depth (max_depth)
- Training and Testing Data
- Gini Index and Entropy
- Model Accuracy
- Overfitting
- Decision Tree Visualization

## Tools and Libraries Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
Pima Indians Diabetes Dataset

The dataset contains medical information used to predict whether a person has diabetes.

## Practical Description
In this practical, a Decision Tree Classifier is implemented using the Pima Indians Diabetes Dataset.

Two decision tree models are created using different maximum depth values. Their performance is compared to understand how tree depth affects model accuracy and complexity.

The decision trees are also visualized to understand their decision-making process.

## How to Run
1. Open the notebook in Google Colab.
2. Upload the required dataset.
3. Run all code cells sequentially.
4. Observe the accuracy and visualizations of both decision tree models.
5. Compare the results of the two models.

## Conclusion
This practical helped us understand Decision Tree Classification and the effect of maximum depth on model performance. We trained and compared two decision tree models with different depths and learned how controlling tree depth can help reduce overfitting and improve model generalization.
