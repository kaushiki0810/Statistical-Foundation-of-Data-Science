# Practical 11 – Monte Carlo and MCMC

## Description
This practical demonstrates Monte Carlo simulation and Markov Chain Monte Carlo (MCMC) techniques using historical monthly sunspot data from 1749 to November 2018.

## Topics Covered
- Sunspot Data Analysis
- Gamma Distribution
- Monte Carlo Simulation
- Metropolis-Hastings Algorithm
- MCMC Sampling
- Burn-in Removal
- Parameter Estimation
- Trace Plots and Histograms

## Libraries Used
- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy

## Dataset
Monthly Mean Total Sunspot Number – SILSO World Data Center.

Dataset: https://www.sidc.be/SILSO/DATA/SN_m_tot_V2.0.csv

## Objective
To model sunspot observations using a Gamma distribution and estimate its parameters using Monte Carlo and MCMC methods.

## Result
Successfully implemented Monte Carlo simulation and MCMC sampling to analyse sunspot data and estimate the Gamma distribution parameters.
