# Practical 9: K-Nearest Neighbors (KNN)

## Aim
To implement the K-Nearest Neighbors (KNN) classification algorithm using the Iris dataset and study how different values of K affect classification performance.

## Objectives
- To understand the working of the KNN algorithm.
- To perform exploratory data analysis on the Iris dataset.
- To separate independent features and the target variable.
- To split the dataset into training and testing sets.
- To apply feature scaling using StandardScaler.
- To train and test the KNN classification model.
- To evaluate model performance using accuracy, confusion matrix, and classification report.
- To compare error rates for different K values.
- To visualize the classification results using PCA.

## Concepts Covered
- K-Nearest Neighbors (KNN)
- Exploratory Data Analysis (EDA)
- Feature Scaling
- Training and Testing Data
- Confusion Matrix
- Accuracy Score
- Precision, Recall and F1-Score
- Error Rate
- Principal Component Analysis (PCA)

## Tools and Libraries Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
Iris Dataset (built-in Scikit-learn dataset).

The dataset contains measurements of three different species of Iris flowers:
- Setosa
- Versicolor
- Virginica

## Practical Description
In this practical, the K-Nearest Neighbors classification algorithm is implemented using the Iris dataset.

The dataset is explored using statistical methods. It is then divided into training and testing sets, and feature scaling is applied.

A KNN model is trained using K=5. Its performance is evaluated using a confusion matrix, accuracy score, and classification report.

Different K values from 1 to 20 are compared using their error rates. Finally, PCA is used to visualize the actual and predicted classes.

## How to Run
1. Open the notebook in Google Colab.
2. Run all code cells sequentially.
3. Observe the model evaluation results.
4. Compare the error rates for different K values.
5. Observe the PCA visualization.

## Conclusion
This practical helped us understand and implement the K-Nearest Neighbors classification algorithm. We performed data exploration, feature scaling, model training, and performance evaluation. We also compared different K values and used PCA to visualize the classification results.
