
# Practical 5: Understanding Two Tailed Test

## Aim
To understand probability and perform a two-tailed Z-test using Python.

## Objectives
- To calculate the probability of evaluation scores greater than a given value.
- To calculate the probability of evaluation scores within a specified range.
- To understand null and alternative hypotheses.
- To calculate the Z-score and p-value.
- To interpret the results of a two-tailed hypothesis test.

## Concepts Covered
- Probability calculation
- Evaluation score distribution
- Null and alternative hypotheses
- Two-tailed hypothesis testing
- Z-score calculation
- P-value calculation
- Significance level
- Statistical decision-making

## Tools and Libraries Used
- Python
- Pandas
- SciPy
- Math

## Dataset
**TeachingRatings.csv**

The dataset contains information about professors, including evaluation scores, age, gender, beauty scores, tenure and other related attributes.

## Practical Description
This practical involves calculating probabilities for evaluation scores greater than 4.5 and between 3.5 and 4.2. It also demonstrates a two-tailed Z-test using given values for the historic mean, population standard deviation, sample size and sample mean to determine whether the mean points scored by regional players differs significantly from the historic mean.

## Conclusion
This practical helped in understanding probability calculations and the application of a two-tailed Z-test. It demonstrated how Z-scores and p-values are used to test hypotheses and make statistical decisions based on a given significance level.
