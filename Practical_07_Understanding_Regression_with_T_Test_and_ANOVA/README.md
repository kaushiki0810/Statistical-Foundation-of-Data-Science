# Practical 7: Understanding Regression with T-Test and ANOVA

## Aim
To study the relationship between teachers' gender, age, beauty scores, and teaching evaluation scores using regression analysis, T-test, and ANOVA.

## Objectives
- To understand regression analysis.
- To examine the relationship between gender and teaching evaluation scores.
- To study differences in beauty scores among different age groups using ANOVA.
- To examine the relationship between beauty scores and teaching evaluation scores.
- To understand regression coefficients and p-values.
- To draw conclusions using the TeachingRatings dataset.

## Concepts Covered
- Linear Regression
- T-Test
- Analysis of Variance (ANOVA)
- Correlation
- Hypothesis Testing
- P-values and Regression Coefficients

## Tools and Libraries Used
- Python
- Google Colab
- Pandas
- Statsmodels
- NumPy

## Practical Description
In this practical, regression analysis is performed using the TeachingRatings dataset.

Three analyses are conducted:
1. Regression analysis to examine the relationship between teachers' gender and evaluation scores.
2. ANOVA to compare beauty scores across different age groups.
3. Regression analysis to examine the relationship between beauty scores and teaching evaluation scores.

The results are interpreted using coefficients, F-statistics, T-statistics, and p-values.

## How to Run
1. Open the Practical file in Google Colab.
2. Upload the `TeachingRatings.csv` dataset.
3. Run all the code cells sequentially.
4. Observe and understand the output.

## Conclusion
This practical helped us understand regression analysis, T-tests, and ANOVA. We examined relationships between different variables in the TeachingRatings dataset and interpreted the statistical results using p-values and regression coefficients.
