# Practical-12: Metropolis Algorithm and Deterministic Model

## Overview
This practical demonstrates two important concepts of Statistics using Python:
1. Implementation of the Metropolis Algorithm.
2. Implementation of a Deterministic Population Growth Model.

Both experiments are performed using Google Colab.

## Part A: Metropolis Algorithm

### Aim
To implement the Metropolis Algorithm to generate samples from a probability distribution using the Markov Chain Monte Carlo (MCMC) technique.

### Description
The Metropolis Algorithm is an MCMC sampling technique used to generate samples from a target probability distribution.

It works by proposing new random values and accepting or rejecting them based on an acceptance probability.

### Concepts Used
- Markov Chain Monte Carlo (MCMC)
- Probability Distribution
- Acceptance and Rejection Sampling
- Normal Distribution
- Statistical Analysis

### Visualizations
- Trace Plot
- Histogram of Generated Samples
- Comparison with Standard Normal Distribution

## Part B: Deterministic Model

### Aim
To implement a deterministic population growth model using Python and visualize population changes over time.

### Description
A deterministic model is a mathematical model in which the output is completely determined by the initial conditions and input parameters.

In this experiment, an exponential population growth model is implemented to study population changes over time.

### Mathematical Formula

N(t) = N0 × e^(rt)

Where:
- N(t) = Population at time t
- N0 = Initial Population
- r = Growth Rate
- t = Time
- e = Euler's Number

### Concepts Used
- Deterministic Modelling
- Exponential Growth
- Mathematical Simulation
- Data Visualization
- Population Analysis

### Visualization
