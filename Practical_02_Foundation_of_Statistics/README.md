
# Practical 2: Foundation of Statistics

## Aim
To understand the fundamental concepts of statistics and perform basic statistical analysis using Python.

## Objectives
- To identify and understand the data types in a dataset.
- To calculate mean, median, minimum and maximum values.
- To generate descriptive statistical summaries.
- To understand data distribution using histograms.
- To analyse beauty scores based on gender.
- To examine the relationship between gender and tenure.

## Concepts Covered
- Data types
- Mean, median, minimum and maximum
- Descriptive statistics
- Frequency distribution
- Histograms
- Group-wise statistical analysis
- Gender and tenure analysis

## Tools and Libraries Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## Dataset
**TeachingRatings.csv**

The dataset contains information about instructors, including their gender, beauty scores, teaching evaluations and tenure status.

## Practical Description
This practical uses statistical methods to explore and summarise the Teaching Ratings dataset. It involves calculating descriptive measures, visualising beauty scores through histograms and analysing differences based on gender and tenure.

## Conclusion
This practical helped in understanding the basic foundations of statistics, including descriptive measures, data distribution and group-wise analysis. It also demonstrated how Python libraries can be used to explore and interpret datasets.
