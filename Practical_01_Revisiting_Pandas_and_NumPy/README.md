# Practical 1: Revisiting Pandas and NumPy

## Aim
To revise the basic concepts of Pandas and NumPy and perform various numerical and matrix operations using Python.

## Objectives
- To understand Pandas and NumPy libraries.
- To create and manipulate a Pandas DataFrame.
- To convert a DataFrame into a NumPy array.
- To understand the shape, size, and dimensions of an array.
- To perform basic arithmetic and matrix operations.

## Concepts Covered
- Importing Pandas and NumPy libraries
- Creating a Pandas DataFrame
- Converting a DataFrame into a NumPy array
- Finding the shape, size, and dimensions of an array
- Array addition and subtraction
- Element-wise multiplication
- Matrix transpose
- Matrix inverse
- Matrix multiplication

## Tools and Libraries Used
- Python
- Google Colab
- Pandas
- NumPy

## Practical Description
This practical demonstrates the use of Pandas and NumPy for data handling and numerical computations. A DataFrame is created using numerical data and converted into a NumPy array. Different arithmetic and matrix operations are then performed.

## Conclusion
This practical provides an understanding of the basic functionalities of Pandas and NumPy and demonstrates how these libraries can be used for data manipulation and numerical operations in Python.
