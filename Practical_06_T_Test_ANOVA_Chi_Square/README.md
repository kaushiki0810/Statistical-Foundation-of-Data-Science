
# Practical 6: Understanding T-Test, ANOVA, Chi-Square

## Aim
To understand and apply different statistical tests, including T-Test, ANOVA, Chi-Square Test and Pearson Correlation, using Python.

## Objectives
- To compare the mean evaluation scores of male and female instructors.
- To compare beauty scores across different age groups.
- To examine the association between tenure and gender.
- To measure the correlation between teaching evaluation and beauty scores.
- To understand p-values and statistical hypothesis testing.

## Concepts Covered
- Independent Two-Sample T-Test
- One-Way ANOVA
- Chi-Square Test
- Pearson Correlation
- Hypothesis testing
- Null and alternative hypotheses
- T-statistic, F-statistic and Chi-square statistic
- P-value and significance level
- Statistical interpretation

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
- Seaborn

## Dataset
**TeachingRatings.csv**

The dataset contains information about professors, including gender, age, beauty scores, teaching evaluation scores and tenure status.

## Practical Description
This practical applies different statistical tests to the Teaching Ratings dataset. It compares teaching evaluation scores by gender using an independent two-sample T-Test, compares beauty scores across age groups using One-Way ANOVA, examines the association between tenure and gender using a Chi-Square Test, and measures the relationship between beauty scores and teaching evaluation scores using Pearson Correlation.

## Conclusion
This practical helped in understanding the application of different statistical tests and correlation analysis. It demonstrated how statistical methods, test statistics and p-values can be used to analyse data and draw conclusions.
